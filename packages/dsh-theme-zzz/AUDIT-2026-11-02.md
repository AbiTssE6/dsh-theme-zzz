## 一、审查方法

四轴机械比对，全部基于“证据”而非猜测：

| 轴 | 判据 |
|---|---|
| A 哈希前缀 | `[class*="xxxxxx_"]` 的六位前缀是否还出现在任一已安装 bundle |
| B 类名 token | 122 个 `[class*=…]` token 是否还存在于 bundle（命中为 0 即死） |
| C 结构冗余 | 重复规则、同选择器后写覆盖（后者必胜，前者永不可能生效） |
| D 变量 | `--zzz-*` 是否被 `var()` 读取；绑定的 `--dsw-*` 是否被 bundle 消费 |

### 查过但**不动**（改了就变行为，不属于清理）

| 项 | 原因 |
|---|---|
| `[class*="_tabHost_ "]`（末尾多一个空格） | 真实 token 是 `_tabHost_`。修掉会让 dock 页签按钮失去设计系统皮肤——那是视觉变更，需单独确认 |
| 637 个 `!important` | 宿主自身有 179 个 `!important`，削减必须逐组件视觉回归；已用棘轮锁死只降不升 |
| 9 处 `:not(#zzz-guard)` | 均为压制宿主同属性 `!important` 的唯一手段，已在样式表顶部登记分组理由 |
